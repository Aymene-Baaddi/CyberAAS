# Sentinel Cybersecurity

Landing page for Kryptos, a cybersecurity-as-a-service practice for organisations in Kuwait. One page, smooth scroll (Lenis) and a pinned method section (GSAP).

## Développement

Node.js et npm sont requis.

```sh
npm install
npm run dev
```

Puis ouvrir l’URL affichée par Vite (par défaut http://localhost:5173).

```sh
npm run build
npm run preview
```
